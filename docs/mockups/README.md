# Aira Sales Kit — refreshed UI mockups

Open `index.html` in any browser. It is a self-contained, responsive prototype with no external assets or build step.

Use the left navigation on desktop or bottom navigation on mobile to switch between **Units**, **Booking detail**, and **Weekly summary**. Resize the browser below 760px to see the mobile treatment.

## Design direction

- Keeps Aira's dark green, warm cream, and lime identity while improving contrast and spacing.
- Makes unit availability the dominant scan target and keeps the primary booking action close to the unit data.
- Turns booking readiness into a visible checklist with a clear next action and audit trail.
- Makes the weekly summary useful at a glance through stronger totals, tower comparison, deposit progress, and compact transaction rows.
- Uses a persistent desktop rail and thumb-friendly mobile bottom navigation.

All names and figures are illustrative and mirror the current product model. This folder is a design artifact only; it does not connect to Supabase or modify production code.
